# 来源、可复现程度与发布检查

## 来源处理

继承材料的来源相对路径、原始 SHA-256、公开 SHA-256 和处理方式已逐文件记录。

六个数值计算文件`linear.py`、`nonlinear.py`、`sequential.py`、`identity.py`、`randomness.py`和`statistics.py`保持原文件字节不变。EuRoC数值内核、数据处理代码、冻结配置、逐帧对CSV也保持不变。v1.0.1修订了公开执行入口、结果校验、汇总边界处理和比较入口；部分审查JSON仅移除私人绝对路径并格式化，科学值和原审查状态不变。

`contract.py`和`authorization.py`是公开离线适配层，不是原服务器执行授权系统。它们校验随包配置的哈希、内存配置的一致性和实例编号范围，不连接远程服务器。`scripts/run_e0.py`调用原数值内核，同时把新输出明确标记为独立复现、待审查。上述适配层没有原历史执行权限的含义。

配置和归档中的旧版本号、历史状态、历史相对路径及引用保持不变；其中部分原执行流程文件不在本最小包内，不能把这些历史字段当成当前发布状态。v1.6范围变化及原六序列未通过记录均保留。

## 可以重算什么

| 层级 | 随包资源 | 能完成的核查 |
|---|---|---|
| EuRoC已运行结果 | 六序列逐帧对指标、两种拟合集大小、全部五种方法 | 重算每序列统计、序列等权对比、描述性bootstrap区间、失败计数和原门槛状态 |
| E0已运行结果 | 三类实验汇总、来源审查、K选择汇总 | 校验文件完整性；不是从全部原子记录重新估计统计量 |
| 新E0运行 | 冻结数据生成、求解和统计基础函数、公开入口 | 生成新的逐问题结果和运行回执；完整历史汇总/审批流水线不随包提供 |
| 新EuRoC运行 | 数据读取、计算、汇总与绘图代码 | 用户提供官方原始数据后可重新执行；结果依赖实际数据与数值环境 |

本包未包含全部E0原子结果包，也未提供原服务器特定的计时预热与审批流水线。因此，“快速复核通过”不能表述为全部实验重新运行通过，更不能表述为完整历史执行环境的逐字节复现。

论文图表、Word/PDF论文草稿、数据集图像、模型检查点、服务器配置和大型绘图产物均不在发布范围。

## 环境

本次公开入口验证使用Python 3.10.20（MSC v.1942，64位Windows）、NumPy 2.2.6、SciPy 1.15.3、OpenCV Python 4.13.0.92、PyYAML 6.0.3、pandas 2.3.3、matplotlib 3.10.8和pytest 8.4.1，对应`requirements.txt`。所用现有环境还装有PyTorch 2.7.1+cu128/CUDA 12.8，但本包不依赖它们。

原EuRoC归档记录Python 3.10.14（GCC 11.2.0）、NumPy 1.26.4、SciPy 1.13.1和OpenCV 4.11.0。`requirements-reference.txt`锁定这些历史核心版本；其余辅助库采用本次已验证版本，不声称它们是原环境的完整快照。原记录未提供CPU具体型号，不以本地硬件补填。

原始图像重新执行可能受OpenCV与数值库版本影响；本次只验证归档指标重算的一致性，不声称跨版本的特征提取和求解逐位相同。
