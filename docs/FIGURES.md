# 结果图复现约定

本包重绘三幅定量结果图，不包括不承载实验结果的流程示意图。后端固定为Python / matplotlib；重绘不改变数值、比较对象、区间或坐标轴定义。

| 图 | 结论与面板 | 证据和统计单位 |
|---|---|---|
| 图2：EuRoC | 三个校准指标的序列差值和随机/精确校正增量时间 | 五条有效样本充足的序列；16条拟合轨迹；每序列先取帧对中位数，再取序列等权中位数；误差线为10,000次序列簇bootstrap的描述性95%分位区间 |
| 图3：受控数值实验 | 探针数选择、线性设置对比、非线性点估计 | 13,500个线性问题；27个设置各500次；200个非线性问题；非线性百分比不是显著性结论 |
| 图4：顺序尺度跟踪 | 稳定误差、误报次数、延迟及边界命中率 | 八个设置各200次独立试验；校正用精确标量块迹；不用于声称真实VIO闭环收益 |

图形类型为定量面板组合。沿用灰色基线、蓝色校正及少量橙色对照；标签与线型共同区分方法。宽度约17–18 cm，SVG/PDF保留可编辑文字，PNG用于预览。图2另导出600 dpi TIFF。没有真实图像的修饰、拼接或生成式替代，也不使用占位数值。

导出后检查坐标与标签、数据和区间、颜色区分、可编辑文字及图源哈希。图3的面板比例和百分比标签位置采用英文版的版式修正，公开绘图入口另压缩中间面板的图例间距，避免遮挡数据点；数值与原始绘图输入一致。
